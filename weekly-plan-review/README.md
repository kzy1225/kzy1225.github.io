# 週間 PLAN & REVIEW

`sample.pdf`の構成を基にした、手書き用の週間シート作成ページです。ISO週を選び、A4横・1ページのPDFを直接ダウンロードします。

## 使い方

1. 「ISO週年」と「週番号」を選択します。前週・次週・今週に戻るボタンでも移動できます。
2. 「日付から選ぶ」でその週に含まれる日を選んでも、対応する月曜〜日曜の週に切り替わります。
3. プレビューを確認して「PDFで出力」を押します。
4. `weekly-plan-review_2026-W43.pdf`のような名前でダウンロードされます。

「印刷する」はブラウザーの印刷画面を開きます。A4・横向き・倍率100％で印刷してください。ブラウザー独自のヘッダーとフッターはオフにします。PDFダウンロードのほうは用紙サイズがファイルに固定されています。

## シートの構成

- 用紙：A4横（297×210mm）、1ページ、余白8mm。
- 上部右側：ISO週年・週番号を14pt、月曜〜日曜の日付範囲を11ptで控えめに表示。日付は落ち着いたグレーとし、見出し周りの余白を詰めて記入欄を広く確保。
- 上段：週間の目標・振り返り、月曜・火曜・水曜。
- 下段：木曜・金曜・土曜・日曜。
- 日別欄：睡眠時間・目標・ToDoの手書き欄。各日の日付は月日と曜日で表示し、年は上部の日付範囲で確認できます。
- 週間欄：目標3件・振り返り3件、勉強時間・労働時間・睡眠時間・支出・チェック数・達成度。
- 右端：毎日以外の11項目をジャンル別の「今週のToDo」にまとめて表示。チェック枠 → 業務名 → ［頻度・所要時間］の順に横並びで配置します。長い項目だけ折り返します。
- 左側の本文は10pt程度を維持。右側の読むためのToDoは本文8pt・補足7pt・ジャンル見出し9ptとし、長い項目名は折り返します。ToDo欄を248ptから168ptに縮め、空いた80ptを左側4列に20ptずつ均等配分しています。
- 下部の重複一覧と日別の分類チェック欄は右端へ集約し、記入スペースを確保しています。

週間シートは手書き用の記入用紙です。日別の振り返り欄は設けず、週間の目標・振り返り欄を残しています。毎月10・20・30日は該当日のToDoへ「買い物」とチェック枠を自動記載します。2月など存在しない30日は追加しません。

## 月間ハビットトラッカー

1. 「シートの種類」で「月間ハビットトラッカー」を選びます。
2. 対象月を選ぶと毎日のルーティーンが自動で表に入ります。追加でやることを1行に1項目で入力できます（追加は最大15項目・各24文字、同名は不可）。自動項目と同名の追加項目は1行にまとめます。
3. やること×日付の表で、できた日のマスをチェックします。色が付き、プレビュー・PDFにも反映されます。
4. 「PDFで出力」または「印刷する」でA4横1枚として出力します。自動項目と追加項目は合計45件まで、行の高さを自動調整して出力します。

月末の日数はうるう年も含め自動調整します。項目とチェックは月別にこのブラウザーのlocalStorageへ保存します。別端末との同期はありません。ブラウザーの保存データを削除すると記録も消えます。チェックは項目名に対応するため、名前を変えると別の習慣として扱います。保存が利用できない場合は画面上に通知します。

## ISO週の扱い

- 月曜始まり、日曜終わり。
- 1月4日を含む週（その年の最初の木曜日を含む週）が第1週。
- 年により52週または53週。
- ISO週年は暦年と異なる場合があります。
- 例：2026-W01は2025/12/29〜2026/01/04。
- 例：2026-W53は2026/12/28〜2027/01/03。
- 初期表示は日本時間の今日を含む週。
- 対応するISO週年は1900〜2100年。日付計算はUTC上の暦日で行い、端末の時差や夏時間による日付ずれを避けます。

## ルーティーンを編集する

編集するファイルは **`routines.json`だけ** です。JavaScriptやHTMLを書き換える必要はありません。

### 日常業務

`groups`の各分類にある`items`を編集します。

```json
{
  "title": "1. 起床後",
  "items": [
    { "name": "水を飲む", "frequency": "起床後30分以内", "minutes": 2 },
    { "name": "今日の予定確認", "frequency": "毎朝", "minutes": 3 }
  ]
}
```

- `title`：分類名。順番はファイルに書いた順です。
- `name`：業務名。
- `frequency`：頻度・実施するタイミング。任意の短い文章で記入します。
- `minutes`：所要時間の分数（0〜1440の整数）。4時間なら`240`。
- 項目を増やす場合は同じ形式の行を追加します。末尾以外の項目にはカンマが必要です。
- JSONにはコメントや末尾カンマを書けません。文字列は半角のダブルクォートで囲みます。

`routine.pdf`の「0. 曜日」「99. 集計」は業務ではないため、ルーティーン一覧から除外しました。集計項目は週間振り返り欄にまとめています。買い物以外の実施日は自動では割り当てません。

### 頻度による自動振り分け

`groups[].items[].frequency` を基準に振り分けます。

- 「毎日」「毎朝」「毎晩」「毎夕」「毎夜」「毎食」「1日○回」「24時間に1回」、および「起床後」「帰宅後」「就寝前」で始まる項目は月間ハビットトラッカーへ自動追加します。
- それ以外（週○回、○日に1回、隔日、毎月など）は週間シート右端のジャンル別ToDoに掲載します。
- 同名の日次項目は分類名を付けて区別します。例：歯磨き（起床後）、歯磨き（就寝前）。
- 週間ToDoのチェック枠数は週○回の回数に合わせ、○日に1回・隔日は7日分の目安を切り上げます。その他の頻度は1枠です。実施日を指定するものではありません。
- 買い物は「毎月10・20・30日」とし、該当日の日別ToDoにも自動記載します。

現在は毎日の30項目を月間表へ、残り11項目を週間シートへ振り分けます。旧 `weeklyChecklist` は互換性のためファイルに残していますが、表示する週間ToDoは `groups` から自動生成するため、今後は `groups` を編集してください。

### 編集の反映と注意点

1. `routines.json`を保存します。
2. 公開する場合はそのファイルもGitHub Pagesに反映します。
3. ページを再読み込みします。ルーティーンはキャッシュを使わず読み直します。
4. プレビューとPDFを確認します。

レイアウトは文字の幅を測り、折り返しと3列への配分を自動調整します。項目を増やしすぎた場合や、長すぎる分類名・週間ToDo名は、黙って切り落とさずエラーにします。A4の1枚に収まるよう表記を短くしてください。日本語フォントにない絵文字や特殊文字はPDF出力時にエラーにし、文字化けしたPDFを出力しません。

## ファイル構成

```text
weekly-plan-review/
  index.html        週選択・プレビュー・ルーティーン一覧
  style.css         ページデザイン・A4横の印刷設定
  app.js            表示・データ読込・PDFダウンロード
  week.mjs          ISO週と日付計算
  sheet.mjs         プレビューとPDFで共用する描画レイアウト
  routines.json     人間が編集する業務・ToDoデータ
  week.test.mjs     年末年始・第53週・レイアウト等のテスト
  README.md         この説明
  sample.pdf        提供された見本（原本を保持）
  routine.pdf       提供された業務一覧（原本を保持）
  vendor/           PDFライブラリ・日本語フォント・ライセンス
```

PDFはブラウザー内で生成し、選択した週やルーティーンの内容をPDF生成サービスへ送信しません。PDFライブラリとフォントは同じサイトに同梱しています。PDFでは日本語フォントを埋め込み、文字と罫線をベクターで保存します。

データ・フォント読込中、読込失敗、無効な週、レイアウトエラーの際は出力できません。生成中は週選択を無効にし、ダウンロードする内容とファイル名が一致するようにします。

ビルド不要。リポジトリのルートから以下で起動できます。

```sh
python3 -m http.server 8000
# http://localhost:8000/weekly-plan-review/
node --test weekly-plan-review/*.test.mjs
```

ES Modulesとデータ取得を使うため、`file://`でHTMLを直接開くのではなくHTTP経由で確認してください。ローカルで作成・検証済みのファイルを用意していますが、この作業でGitHub Pagesの本番公開は行っていません。

## speck.pdf に合わせた表示

ハビットトラッカーは「やること・所要時間・各日」の表にし、独立したジャンル列を設けません。ジャンルごとに黒の太字・薄い灰色背景の見出し行（日付欄の右端まで背景を延長）を入れ、見出しの時間欄にはそのジャンルの合計、各項目の時間欄には個別の所要時間を表示します。ジャンル行にはチェック欄を設けず、各項目だけをチェックします。画面・印刷・PDFに共通で反映します。

合計はその表にある各項目の所要時間を1回分ずつ足した値です。自由追加した項目は「追加項目」にまとめ、時間未設定（「—」）として合計には含めません。朝夜の同名項目はジャンル見出しで区別し、保存済みのチェックは従来のキーを維持します。

週間ToDoはジャンルごとにまとめ、「チェック枠 → やること → ［頻度・所要時間］」の順に横並びで表示します。長い項目は文字を縮小せず折り返します。各ジャンルに含まれる項目1回分の合計も見出しに表示します。

月間ハビットトラッカーは月曜始まりの週区切りを示すため、日曜日の列を薄い灰色、日曜の右罫線を太線で表示します。ジャンル見出しの灰色とチェック済みの緑色を優先し、画面・印刷・PDFに共通で反映します。

月間表は月の日数にかかわらず31列固定です。日付の下に曜日を表示し、月末以降の列は空欄（チェック不可）にします。週区切りの説明文は表示しません。
