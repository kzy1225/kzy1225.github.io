# 現金合計・列別分析

## 使い方

- 10券種（10,000・5,000・2,000・1,000・500・100・50・10・5・1円）を1〜8列で集計します。
- 列名は任意に編集できます。空欄は0枚。入力可能な枚数は0〜1,000,000の整数です。
- `10+5`、`50*2`、`(10+5)*2`などの四則演算に対応します。小数を含む式も、最終結果が整数枚なら利用できます。
- **画面テンキーON**：独自のソフトウェアキーボードを表示します。端末標準キーボードを抑制するため入力欄はreadonly/inputmode=none。物理キーボードの数字・演算子・削除・Enter・Escapeにも対応します。
- **OFF**：通常の入力欄に切り替わり、端末標準キーボード／物理キーボードで入力できます。OSのキーボード表示そのものを強制的に制御する機能ではありません。
- テンキーも通常入力も、入力のたびに計算・保存します。未完成式や不正な枚数がある場合は、集計・分析の結果を「—」にし、誤集計を防ぎます。
- テンキーを閉じる・別セルへ移る際も、入力中の式は残ります。「確定して閉じる」は式を計算結果へ置き換えます。
- 列を減らすと右端の列が非表示になります。データは保持し、増やすと復元します。非表示列は合計・分析から除外します。

## 分析

表の下に分析欄を設置します。

1. **選択列の合計**：チェックした任意の列の合計金額・合計枚数・券種別内訳。
2. **2列ずつの組み合わせ**：表示列の全てのペアを一度ずつ表示。4列なら6通り、8列なら28通り。

各ペアは独立した集計です。複数ペアに同じ列が含まれるため、ペア合計を縦に足して全体合計として扱うことはできません。

## 保存

`localStorage`の`kzy1225.cash.v2`に列数、全8列の入力と名前、テンキー設定、分析対象を保存します。非表示の列も保存します。保存できない場合は画面に表示し、計算は続行します。不正・破損した保存内容でアプリ全体を停止させません。

全リセットは確認後に非表示列を含む入力を消去します。テンキーON/OFFの好みは維持します。他のツールの保存データは消去しません。

## 点検で修正した点

| 旧版の問題 | 修正 |
| --- | --- |
| 列を減らして再度増やすと右端列の値が消える | DOMから独立した8列の状態を保持 |
| テンキー編集中の±1／±10が確定済みの古い値を参照する | 現在の式を評価してから増減 |
| テンキーの外を押すと未確定の入力が消える | 編集内容を即時にモデル・保存へ反映 |
| リロードで全入力が失われる | 自動保存・復元を追加 |
| 枚数の上限がなく安全な整数精度を超え得る | 1セル100万枚・8列・10券種の範囲を検証 |
| readonlyかつタップ専用で入力方法を切り替えられない | 画面テンキー切替と物理キーボード操作 |
| 動的Function評価に依存 | 四則演算専用の構文解析へ変更。有理数で中間計算 |

## 実装

- `index.html`：画面構造とテンキー。
- `style.css`：集計画面固有のスタイル。
- `app.js`：入力、保存、テンキー、列管理、結果表示。
- `calc.mjs`：枚数の式解析、集計、列結合、ペア計算。
- `calc.test.mjs`：計算の境界・エラー・全ペアを検証。
- 共通レイアウトは`../assets/site.css`と`../assets/site.js`。

検証コマンド：

```sh
node --test total-the-cash/calc.test.mjs welkatsu/calc.test.mjs
```

ブラウザーではHTTPサーバー経由で開いてください（ES Modules使用）。
