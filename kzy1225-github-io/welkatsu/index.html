計算の前提と、利用ルール

1.5倍になる条件

毎月20日、対象店舗でWAON POINTを200pt以上利用する場合を試算します。対象商品が税込300円未満、または今回利用可能なポイントが200pt未満なら、通常の1pt＝1円で計算します。ポイント支払い分の新たなポイント付与は含めません。

対象外店舗・Vポイントのみ対応の例外店舗・ネットショップには対応していません。

1日の上限と、11月の変更

通常店舗は2026年10月20日まで30,000pt、11月20日以降5,000pt。ウエルシアプラスは30,000ptを継続。コクミンは11月20日以降10,000pt。MASAYA・COLOR STUDIO・NARCISは2026年4月20日以降10,000ptです。当日使用済み分を差し引きます。

消費税と端数はどう計算する？

税抜価格×数量を8％・10％ごとに合計し、税率ごとに1回端数処理します。初期設定は切り捨てですが、法律が切り捨てだけを指定しているわけではありません。実店舗の処理に合わせて変更できます。

価格は値引き後の税抜価格（整数円）を入力。行ごとの金額は税抜小計です。税率別に合算するため、税込単価を丸めて個数倍する方法とは異なります。表示税額はポイント充当前の参考額です。

ポイントの端数と試算の限界

1.5倍分の1円未満は切り捨て、必要ptは選択により切り上げ／切り捨てとするモデルです。ポイント充当額は商品合計までとし、お釣りは計上しません。公式資料ではレジの詳細な端数処理を確認できていません。

「最大個数」は必要ptを切り上げて、現金0円で買える数を試算します。最低利用条件も判定します。クーポンの自動適用、ポイント交換、支払い方法別の還元は対象外です。

対応する買い物日：2026年4月20日〜2027年3月20日の各20日。以後の税制・キャンペーン変更は再確認が必要です。
